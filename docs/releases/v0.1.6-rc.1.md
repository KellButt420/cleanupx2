# cleanup 0.1.6-rc.1

This preview strengthens file-operation safety, crash recovery and memory bounds.

Download **Cleanup.exe** for the portable app, or **cleanup-0.1.6-windows-x64-setup.exe**
for a per-user installation. Windows 11 x64 is required. Both downloads include their runtimes.

## Changes

- Organizer moves and undo use the same locked file handle that was checked. Cross-drive copies preserve named data streams and dates, and leave unsupported files in place.
- Interrupted moves and undo can be recovered from prepared file identities recorded before the change.
- Leftover removal requires a fresh, one-use approval of the reviewed files or registry data and checks for reinstalled apps.
- Steam metadata parsing, storage probes, game scans and history loading have limits to keep malformed data and stalled storage from exhausting resources.
- History shows 20 changes per page, with an Older changes button. Search and filters apply to the current page.
- Update checks compare preview versions correctly and preserve the stable/preview channel distinction.
- Uninstall waiting checks the actual job process count so a missed notification cannot stall the queue.
- Explorer launches use the Windows executable path, and completed animation timers release their callbacks.

## Installation and data

Keep **CleanupData** beside the portable EXE to carry settings and history between PCs.
If that directory is read-only, the app uses the current user's profile. Setup preserves user data on uninstall.
Existing history remains readable. This release uses native ABI 3; keep its frontend and native library together.

## Preview status

These downloads are **unsigned**. Windows may show an unknown-publisher warning, and managed-device policies or Smart App Control can block unsigned applications. Some official uninstallers may request Windows approval.

Local verification covered 90 native checks, seven managed checks, release packaging, portable startup, navigation, a disposable organizer round trip and per-user install/uninstall. Clean-machine/MOTW/UAC coverage and long-duration hardware profiling remain release validation work. This preview does not claim trusted signing or universal compatibility.

The release workflow builds from the tagged source, runs dependency-advisory gates and records build provenance. SHA-256 checksums and dependency notices accompany the downloads.
