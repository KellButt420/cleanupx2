Build notes

cleanup is a native Windows 11 app built with C#, .NET 10, and WinUI 3, with a Rust library for discovery, uninstall, and file operations. It is a development build, not a production release.

The source is on GitHub. A production-signed public installer and WinGet package are still being prepared. Development builds are signed with a local certificate and should not be shared as releases.

Release status

  • Signed MSIX installation and fixture workflows pass on the development machine.
  • Clean-machine release certification and production signing are pending.
  • Memory use is above the original target, so the project makes no performance claims.
  • Windows 11 x64 only. ARM64, macOS, and Linux builds are not planned for the first release.

Build from source

Install .NET SDK 10.0.402 or a later .NET 10 SDK, Rust 1.99.0 (MSVC), Visual Studio 2022 C++ Build Tools, Windows SDK 10.0.26100.0, and PowerShell 7. From the repository root:

. .\scripts\env.ps1
.\scripts\verify-core.ps1
.\scripts\package-dev.ps1

Install a development build

Trust the public development signer once from an elevated PowerShell, then install from a normal one:

# Elevated, once
.\packaging\Trust-DevCertificate.ps1

# Normal PowerShell
.\scripts\install-dev.ps1 -Mode Msix

Remove development trust later with .\packaging\Trust-DevCertificate.ps1 -Remove.

WinGet

cleanup isn’t in the WinGet community repository yet. Publishing needs three things that don’t exist so far: a public release download, a production-signed MSIX, and a registered package identifier.

The website includes a manifest generator for that first release. It hashes the published MSIX and writes version, locale, and installer manifests in the layout winget-pkgs expects:

cd website
bun run winget:prepare --id Publisher.Cleanup --version 1.0.0 \
  --url https://example.com/cleanup-1.0.0-x64.msix \
  --file ..\artifacts\release\cleanup-1.0.0-x64.msix \
  --publisher "cleanup contributors"

winget validate --manifest winget-output\manifests\p\Publisher\Cleanup\1.0.0
winget install --manifest winget-output\manifests\p\Publisher\Cleanup\1.0.0

Validate and test-install locally, then submit the folder as a pull request to microsoft/winget-pkgs. Once the package is accepted, set VITE_WINGET_ID and the WinGet tab on the home page shows the install command.

Updates and support

Release installations will use Windows App Installer to check for signed updates on launch. Direct development MSIX installs do not have an update feed. Your settings and history stay in Windows-managed app data.

Find downloads on GitHub Releases, or get help in Discord.

What cleanup won’t do

It isn’t a registry cleaner, a PC booster, or a debloater. It doesn’t run in the background. Uninstalls always use the application’s official uninstaller after you confirm the list, and leftovers get their own review with nothing preselected.
