A few good
questions.

What does cleanup actually do?+

cleanup removes selected applications through their official uninstallers, offers a separate review of leftovers, and organizes files into folders after you review a preview. History records results and offers undo for eligible file moves.

Will it touch files without asking?+

Folder moves require a preview and confirmation. You can deselect files before continuing. Subfolders, protected paths, links, hidden and system files, partial downloads, and online-only cloud files are preserved. Existing files are never silently overwritten.

Can I undo everything?+

Undo applies to eligible file moves, not application uninstalls. A file must be unchanged and its original path must be available. History shows the result when a file can’t be restored.

Is this a registry cleaner or a PC booster?+

No. cleanup focuses on removing applications, reviewing their leftovers, and organizing folders. It doesn’t promise performance boosts, automatically debloat Windows, or run a background cleanup service.

What do I need to run it?+

The current development build targets Windows 11 on x64. ARM64, macOS, and Linux builds aren’t available. See the development notes for source build prerequisites and local signing instructions.

Can I install it with WinGet?+

Not yet. Release manifest tooling is included, but a public installer and registered package ID are still needed. Once the package is published, the WinGet tab above will show its exact install command.

Is cleanup open source?+

Yes. cleanup is MIT licensed. Browse the source and report issues on GitHub.
